This is a Colorful Login Page with the following features:

Background Animation: The page has a full-screen gradient background with a smooth hue-rotation animation using @keyframes.

Blurred Login Box Background: The login form has a blurred background image applied using a ::before pseudo-element with filter: blur(5px).

Interactive Input Fields: Input fields expand smoothly on focus (transition: width 0.5s ease). Labels transform and rotate with gradient text effects when the user types in the input fields.

Responsive Design: The form is centered using flexbox and adapts to different screen sizes.


Additional Features:

"Remember me" checkbox and "Forgot Password" link.

A "Register" link for users without an account.

This design combines modern CSS techniques like animations, gradients, and transformations to create an engaging and visually appealing login page.
